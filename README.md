I'm Cosmin, a software developer working remotely from Romania. Most of my time goes into [Side Whisper](https://sidewhisper.app), a sidebar for Windows that docks your web apps and Windows apps to the edge of the screen. The rest goes into [Stonewright](https://github.com/cosmincraciun97/stonewright-wp-mcp), an open-source WordPress plugin for AI agents. It takes a snapshot before every change, so anything they do can be rolled back.
